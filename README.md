## Requirements

```bash
pip install pygame
```

## How to Run

```bash
python main.py
```

## Controls

- **Arrow Keys** or **WASD**: Move the snake
- **SPACE**: Pause/Resume
- **ESC**: Quit Game
- **R**: Restart Game (on Game Over screen)

## Game Modes

1. **Classic Mode**: Traditional snake gameplay
2. **Survival Mode**: Obstacles appear randomly
3. **Time Attack**: Complete objective in limited time
4. **Endless Mode**: Play as long as you can

## Difficulty Levels

- **Easy**: Slow snake, more time to think
- **Medium**: Normal speed gameplay
- **Hard**: Fast snake, challenging obstacles
- **Extreme**: Maximum speed and difficulty
